# UIコンセプト

画像生成で作った比較用の方向性。実行画面ではなく、使用データも架空。

- `01-quiet-focus.png`: ダーク。「今日」のタスクと時間軸を並べ、作業枠へのつながりを見せる。
- `02-week-canvas.png`: ライト。週の空き時間を中心に、未配置タスクを横へ置く。

同じ製品・同じ週・同じタスクを使って、情報の見渡し方を比較する。色はRadixを方向性の指示として与えたもので、生成画像の画素が実際のtokenと一致する保証はない。実装の色は `../tokens.json` と `../palettes.json` を使う。

## レビューの観点

- タスクと予定の情報が重複しすぎないか。
- タスクと作業枠の関連が理解できるか。関連アイコンを全行に付ける必要があるか。
- ナビゲーション、入力中のフォーカス、予定の分類が、同じ青で競合しないか。
- Androidで一番よく行う操作に無理なく指が届くか。
- 小さい文字、長い日本語、空状態、予定の密集、文字拡大でも成立するか。

01の既知の欠点: 生成画像の時刻とブロック位置にずれがある。タイムゾーン表記も生成時の例で、ユーザー設定ではない。実装では開始・終了から座標を計算し、時刻・表示倍率を固定して確認する。画像のグラデーションや陰影の一部も、フラットで控えめな製品方針に合わせて見直す。

画像は採用デザインの決定を意味しない。次はこの構成を日本語の部品ギャラリーとネイティブの縦断画面に落とし、操作したときの品質を評価する。
